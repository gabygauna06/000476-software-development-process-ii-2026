# Course Documents

General official documentation applicable to Software Development Process II as a whole.

[Versión en español](README.es.md)

## Purpose

This directory stores formal documents provided by the course that describe its general organization, contents, requirements, or academic planning.

## Current Contents

- `course-syllabus.pdf`: official course syllabus currently available
- `course-schedule.xlsx`: official schedule for the 2026 course

## Naming Conventions

Course-wide documents use stable and descriptive English names.

Established conventions include:

- `course-syllabus.pdf`: official course syllabus
- `course-schedule.xlsx`: official course schedule

Additional names will be defined only when new documents are actually incorporated.

## Document Preservation

Official documents should preserve the content provided by the course.

Renaming a file for repository organization does not imply modifying its academic contents.
