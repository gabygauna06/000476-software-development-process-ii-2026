# Personal Records

Personal and administrative documentation related to the student's participation in Software Development Process II.

[Versión en español](README.es.md)

## Purpose

This directory stores administrative records that belong specifically to the student rather than to the course as a whole.

Examples include:

- enrollment receipts
- administrative confirmations
- course-related personal records

## Current Contents

- `enrollment-receipt-2026-07-30.png`: course enrollment receipt for the 2026 academic year

## Usage Criterion

This directory should only contain personal or administrative documentation directly related to the student's participation in the course.

General course documents belong in `../course-documents/`.
