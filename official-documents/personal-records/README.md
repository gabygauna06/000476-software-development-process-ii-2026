# Personal Records

Personal and administrative documentation related to the student's participation in Software Development Process II.

[Versión en español](README.es.md)

## Purpose

This directory is reserved for administrative records that belong specifically to the student rather than to the course as a whole.

Possible contents include:

- enrollment receipts
- administrative confirmations
- course-related personal records

## Privacy Criterion

Personal documents may contain identifying or sensitive information.

Before committing any personal document to a public repository, the file must be reviewed and unnecessary personal information should be removed or redacted.

## Current Status

The directory has been created because a course enrollment receipt is available.

The original receipt should not be published in the public repository while it contains unnecessary personal identifiers.
