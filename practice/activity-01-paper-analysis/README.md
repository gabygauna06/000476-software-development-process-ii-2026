# Activity 01 — Paper Analysis

First practical activity for Software Development Process II.

[Versión en español](README.es.md)

## Objective

The activity consists of reading and analyzing a scientific paper selected from the proceedings of CONAIISI 2024.

The assigned paper for this group is:

**Sentiment analysis in social networks and online search engines. Financial predictive approach: a systematic mapping of the literature.**

The source paper is stored separately in:

`../../references/papers/01-sentiment-analysis-financial-predictive-approach.pdf`

## Questions

The activity requires answering the following questions:

1. What was the problem?
2. What solution is proposed?
3. What design decisions appear?
4. What quality attributes does the solution attempt to improve?
