# References

External academic and technical reference material used in Software Development Process II.

[Versión en español](README.es.md)

## Purpose

This section contains material that supports course activities and study but is not itself produced as regular theoretical course material.

## Current Structure

- `papers/`: scientific papers and academic articles used during the course

## Organization Criterion

Reference material is classified according to its type and academic purpose.

New categories are created only when actual reference material requires them.

Course presentations and theoretical documents belong in `../theory/`, while official administrative documentation belongs in `../official-documents/`.
