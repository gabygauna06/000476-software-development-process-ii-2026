## Paper 01

**Title:** Sentiment analysis in social networks and online search engines. Financial predictive approach: a systematic mapping of the literature.

The paper examines the use of sentiment analysis applied to social networks and online information sources for financial prediction.

It was assigned during Class 1 as part of Activity 1, which asks students to identify:

1. the problem addressed
2. the proposed solution
3. the design decisions involved
4. the quality attributes the solution attempts to improve
