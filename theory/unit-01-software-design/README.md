# Unit 01 — Software Design

Theoretical material corresponding to the first official topic of Software Development Process II: **Software Design**.

[Versión en español](README.es.md)

## Official Scope

According to the course syllabus, this unit covers:

- software design concepts
- design principles
- architectural design
- data design
- component design
- user interface design

## Current Contents

- `01-software-design-architecture-and-design-patterns-class-material.pdf`: Class 1 presentation introducing the course and reviewing software design, architecture, abstraction levels, and software quality attributes

## Class 01

The first class introduces the general direction of the course and places particular emphasis on the design stage of the software development lifecycle.

The material reviews:

- the software development lifecycle
- the role of software design
- abstraction levels in design
- architecture, subsystems, modules, design classes, and code
- software quality attributes
- the relationship between design, architecture, UML, patterns, and agile development

Additional theoretical material will be incorporated as it is provided during the course.
